## 4. comon119 PnL-diskrepans

**Root cause identificeret:** Leaderboard PnL = **realized + unrealized (mark-to-market)**. Closed-positions API = **kun resolved bets**.

| Kilde | PnL |
|-------|-----|
| Leaderboard (ALL) | **−$2.9M** |
| Sum closed `realizedPnl` (1,695 pos) | **+$19.8M** |
| Sum open `cashPnl` (1,696 pos) | **−$22.8M** |
| Closed + open cashPnl | **−$3.0M** ≈ leaderboard ✓ |

- **Open positions:** 1,696 stk., initial value ~$23.3M, current value ~$522k
- **Worst open:** mange sports-bets og "China invade Taiwan" med `currentValue=0` men stor negativ `cashPnl` — tabte bets der endnu ikke er flyttet til closed-positions API
- **Activity sample (500):** kun `TRADE` — ingen redeems/transfers i sample
- **Tidsperiode:** closed range 2024-10-20 → 2026-05-20 (ALL-perioden dækkes)
- **comon119 er IKKE i top 100 PnL** (rank ~2.7M på PnL-leaderboard) — profilen fra VOL-run var misvisende positiv

**Konklusion for data-pålidelighed:** Brug aldrig closed-positions alene som "total PnL". Leaderboard PnL matcher closed + unrealized. For copy-trading research skal vi filtrere på **leaderboard PnL** (eller closed + open), ikke closed alene.
